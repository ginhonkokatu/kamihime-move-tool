「kamihimemoveeditor（仮）」by 銀本不足


ダウンロードいただきありがとうございま寸止め

プログラミング練習のために開発したツールですが実用性が高いため（自画自賛）配布することにしま舌責め

高難易度レイドや競技会、伏魔殿での行動を煮詰めるのにご利用くださインポ




使い方（PCでの操作を推奨します）

①ZIPを解凍
②index.htmlをダブルクリック
③ブラウザで開く

更新履歴


dev_0.2

・各アビリティの色を任意で設定できるようにしました。ボタンの上で右クリックすれば色を変更できます。なお、反心想・昇華・契晶など一部の特殊キャラは灰色で対応してください。

・メモ機能を実装しました。「ここでカイザーを召喚」「このアビを使う前にボトルで回復」など注意書きなどにも使えます。

・行削除機能を追加しました。行動欄の右端にあるバツを押すとその行動だけを削除できます。

・履歴全消去機能を追加しました。

・ターンごとの横表示に対応しました。

dev_0.3

・JSON保存/読み込みに対応しました。行動履歴のアビリティの色、英霊や神姫の枠で設定したアビリティの色も同時に保存・読み込みできます。

・キャラごとの各アビの累計発動回数、ターンごとの色別総発動回数をカウントするようにしました。

dev_0.4

・召喚攻撃ボタンを作成しました。

dev_0.5

・ターン内の行動順序をドラッグアンドドロップで入れ替えられるようにしました。
